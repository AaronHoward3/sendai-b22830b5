# Hero Block Diversity Summary

## Layout Types (12 Total Hero Blocks)

### 1. **Background Image with Overlay Text** (4 blocks)
- `heroBold1` - Large background image with centered text overlay
- `heroMinimal1` - Clean background image with minimal text overlay  
- `heroMinimal3` - Medium background image with centered text
- `heroMinimal4` - Large background image with big text
- `heroOverlayText` - Background image with styled overlay boxes

### 2. **Image Above Text** (3 blocks)
- `heroBold2` - Text with dividers above full-width image
- `heroBold3` - Simple text above full-width image
- `heroMinimal2` - Image above centered text
- `heroMinimalCentered` - Image above clean text with CTA button
- `heroBoldStacked` - Image above bold black section with CTA

### 3. **Split Layout** (1 block)
- `heroSplitImage` - 60/40 split with image on left, text + CTA on right

### 4. **Image with Overlay** (1 block)
- `heroBold4` - Full-width image with text overlay on top

## Key Features

✅ **All blocks have `https://CUSTOMHEROIMAGE.COM` placeholder**
✅ **Diverse layouts**: Background overlays, image-above-text, split layouts, overlays
✅ **Consistent placeholders**: `{{hero_title}}`, `{{hero_subtitle}}`, `{{cta_url}}`, `{{cta_button_label}}`
✅ **Proper MJML structure**: No self-closing tags, proper nesting
✅ **Visual variety**: Different padding, font sizes, colors, and arrangements
